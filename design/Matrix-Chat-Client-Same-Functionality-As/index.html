Matrix desktop client · UI exploration

Three directions for a chat client with element-web parity.

Each concept is a clickable prototype using the same rooms, people and messages, so you can compare them directly. Spaces, threads, replies, reactions, polls, files, members, E2EE verification and calls are present in all three, each presented differently.

A · Nebula

Dark and dense, closest to Element's mental model. A spaces rail, filtered room list, threaded timeline and a docked right panel. A picture-in-picture call tile floats over the chat.
